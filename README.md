# The Student Growth Hub (TSGH) 🚀

> **Beyond Grades. Beyond Limitations. Discover. Learn. Grow. Lead.**

Official digital platform for **The Student Growth Hub (TSGH)**, a global youth-led student development organisation empowering students across 37+ countries to thrive academically, professionally, and personally.

---

## 🌟 Key Highlights & Impact
- **19,000+** Followers on LinkedIn
- **37+** Countries Reached
- **1,500+** Active WhatsApp Community Members
- **250+** Verified Opportunity Outcomes (Scholarships, Internships, Fellowships)

## 🛠️ Tech Stack & Performance Architecture
- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/) with React 19 & TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with semantic color tokens
- **Icons**: [Lucide React](https://lucide.dev/)
- **Image Pipeline**: `next/image` with AVIF/WebP auto-compression and blur placeholders for ultra-fast load times globally
- **Hosting & CI/CD**: [Vercel](https://vercel.com/) with edge deployment and GitHub integration

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build for Production
```bash
npm run build
npm run start
```
